Grant Expenditure: Sampling & Inference Explorer

Explore how outlier treatment changes the observed distribution, sample means, uncertainty, and a two-sided one-sample t-test. The expenditure values are embedded in this file, so no CSV is needed after opening it.

1. Choose the data view

All valid observed expenditure values are included. Large values can strongly affect the mean and spread.

2. Interactive sampling experiment

Repeatedly draw random samples from the selected data view, calculate each sample mean, and inspect the sampling distribution. Change the sample size and number of repetitions, then press Run experiment.

Sampling Distribution of the Mean (n = 30)

95% Confidence Interval

Interpretation: the hypothesized mean is a fixed reference value, not the observed data mean. The test statistic is t = (sample mean − H₀) / (sample SD / √n). This explorer uses a large-sample 1.96 multiplier to display an approximate 95% interval and decision; use the t critical value for an exact small-sample t interval.

3. What the experiment demonstrates

Population distribution

Skewed expenditure data may contain a long upper tail. The mean is sensitive to extreme observations, while the median is more resistant.

Sampling distribution

As sample size increases, sample means generally vary less. Removing IQR outliers changes the population being sampled, so results from the two tabs answer different questions.

Outlier rule used

Values below Q1 − 1.5 × IQR or above Q3 + 1.5 × IQR are excluded. This is a rule for flagging unusually distant values, not proof that they are errors.

Hypothesis test

For a two-sided test at α = 0.05, reject H₀ when the p-value is below 0.05, or when the 95% confidence interval excludes H₀. This demo reports a normal approximation for the p-value.
